# HR Analytics Dashboard | Power BI

## Project Overview
This project focuses on HR Analytics using Power BI to analyze workforce data and generate meaningful business insights.

The dashboard provides an overview of employee demographics, hiring trends, workforce distribution, and key HR performance indicators.

## Objectives
- Analyze employee demographics and workforce distribution.
- Understand hiring trends.
- Track important HR KPIs.
- Identify patterns to support data-driven HR decisions.

## Tools & Technologies
- Power BI
- Microsoft Excel / CSV
- Power Query
- Data Visualization

## Project Files
- `HR_Analysis.pbix` – Interactive Power BI dashboard.
- `project_hr_analytics.csv` – Dataset used for analysis.
- `HR_Analytics_Report.docx` – Project documentation and findings.
- `HR_Analytics_Presentation.pptx` – Project presentation.

## Project Workflow
1. Data collection
2. Data cleaning and transformation using Power Query.
3. Data analysis and KPI development.
4. Dashboard creation using Power BI.
5. Insights generation and reporting.

## Key Analysis Areas
- Employee demographics
- Hiring trends
- Workforce breakdowns
- HR performance indicators

## Project Outcome
Developed an interactive HR Analytics dashboard to support workforce analysis and help understand HR trends through data visualization.
